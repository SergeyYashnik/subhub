Subscriptions API Service
Микросервис на Go для учета и агрегации данных об онлайн-подписках пользователей. Позволяет управлять записями и рассчитывать реальные затраты за выбранные периоды.

---

Основные возможности
• CRUDL интерфейс: Полный набор операций для управления подписками.

• Расчет статистики: Автоматический подсчет суммарных затрат пользователя за период с учетом количества месяцев активности подписки.

• Авто-миграции: БД актуализируется автоматически при каждом старте приложения.

• Swagger UI: Интерактивная документация, доступная прямо в браузере.

• Dockerized: Быстрое развертывание всей инфраструктуры через Docker Compose.

---

Быстрый старт
1. Настройка окружения Создайте файл `.env` в корне проекта и заполните его данными.

```ini
# Общие настройки

APP_URL=http://localhost:3004

ENV=local

# Настройки сервера

APP_PORT=3000

APP_EXTERNAL_PORT=3004

# Настройки базы данных (PostgreSQL)

DB_USER=postgres

DB_PASSWORD=postgres_pass

DB_NAME=subscriptions_db

DB_HOST=db

DB_PORT=5432

DB_EXTERNAL_PORT=5436

# DSN для подключения

DB_DSN="postgres://${DB_USER}:${DB_PASSWORD}@${DB_HOST}:${DB_PORT}/${DB_NAME}?sslmode=disable"

```

2. Запуск через Docker

```

docker-compose up -d --build

```

После запуска сервис автоматически применит миграции из папки `/migrations` и поднимет HTTP-сервер.

## API Эндпоинты

| Метод | Путь | Описание |
| :--- | :--- | :--- |
| **GET** | `/subscriptions` | Получить список всех подписок пользователя. |
| **POST** | `/subscriptions` | Создать новую запись о подписке. |
| **GET** | `/subscriptions/{id}` | Получить подробную информацию о подписке по её ID (UUID). |
| **PUT** | `/subscriptions/{id}` | Обновить данные существующей подписки (поддерживает частичное обновление). |
| **DELETE** | `/subscriptions/{id}` | Удалить запись о подписке. |
| **GET** | `/subscriptions/stats` | Получить расчет суммарных затрат за выбранный период. |

### Подробности по расчету статистики (`/stats`)
Для получения корректных данных необходимо передать обязательные Query-параметры:

* **user_id** (UUID): Идентификатор пользователя.
* **from** (string): Месяц и год начала периода в формате `MM-YYYY` (например, `01-2025`).
* **to** (string): Месяц и год конца периода в формате `MM-YYYY` (например, `06-2025`).
* **service_name** (string, optional): Фильтр по названию конкретного сервиса (например, `Taxi`).

**Пример запроса:**
`GET /subscriptions/stats?user_id=...&from=01-2026&to=06-2026`
